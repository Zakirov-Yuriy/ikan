## Предложение по устройству

Два варианта, решение за Анной.

1. Как в ЛИДЛЕ: `backend-ikan` (Laravel, API и база, фотографии) и
   `admin-project-ikan` (Laravel, Blade, та же база). Три приложения на
   хостинге: сайт, бэкенд, админка. Каждое новое поле правится в двух
   местах (модели бэкенда и модели админки), две папки фотографий или
   общая, два деплоя.
2. Одно приложение `backend-ikan`: API для сайта по адресам `/api/...` и
   админка по `/admin/...` в том же Laravel, вид страниц скопирован с
   `admin-project` ЛИДЛЕ. Одна база, одни модели, одна папка фотографий,
   один деплой. Для сайта с одним заказчиком и сотнями объектов этого
   достаточно, второй вариант быстрее и дешевле в сопровождении.

Моя рекомендация: вариант 2. Если Анне нужен именно отдельный проект
админки, вариант 1 делается теми же командами, вторая команда создаёт
`admin-project-ikan`.

Сайт при любом варианте: страницы берут данные из API при сборке и
обновляются по сигналу от админки при сохранении (Next revalidate), так
что остаются быстрыми; `next start` на хостинге под Node.

Хостинг, когда дадут: нужен сервер с Node (сайт) и PHP 8.3+ с MySQL или
PostgreSQL (бэкенд); на обычном «виртуальном хостинге» только под PHP
сайт на Next не запустится. Локально у Анны: SQLite, ничего ставить
кроме PHP не нужно; на сервере база меняется записью в `.env`, миграции
те же.

## Команды для Анны

Установка PHP, Composer и установщика Laravel, PowerShell от
администратора, один раз (из документации Laravel 13):

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://php.new/install/windows/8.5'))
```

После неё закрыть и открыть PowerShell заново. Проверка: `php -v`,
`composer -V`, `laravel -V`.

Создание бэкенда (обычный PowerShell, папка рядом с сайтом):

```powershell
Set-Location "C:\Users\zakco\VS Code" -ErrorAction Stop; laravel new backend-ikan --no-interaction --database=sqlite --no-node --no-boost --git; Set-Location backend-ikan; php artisan serve
```

Адрес http://localhost:8000, стартовая страница Laravel. Остановка Ctrl+C.

Если два проекта, то же для админки, порт 8001:

```powershell
Set-Location "C:\Users\zakco\VS Code" -ErrorAction Stop; laravel new admin-project-ikan --no-interaction --database=sqlite --no-node --no-boost --git; Set-Location admin-project-ikan; php artisan serve --port=8001
```

`--git` делает первый коммит сам; `.gitignore` Laravel исключает `.env`,
`vendor`, базу SQLite. После создания репозитория на GitHub команда
отправки будет такой же, как у сайта, с другим адресом.
