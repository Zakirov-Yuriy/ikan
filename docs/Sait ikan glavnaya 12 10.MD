# Сайт ИКАН: среда и главная страница, 12.10.2026

Продолжение файла `claude/sait-ikan-start.md`. Отдельный проект, не ЛИДЛЕ.

Статус: главная свёрстана для компьютера и телефона и отдана архивом
`ikan-glavnaya-12-10.zip`. Анна результат ещё не смотрела, правки по её
замечаниям впереди.

## Среда на компьютере Анны

Windows, VS Code, PowerShell.

- Node.js 24.20.0, поставлен через `winget install --id OpenJS.NodeJS.LTS`.
- npm 11.19.0, Git 2.55.
- Для npm понадобилось разрешить сценарии:
  `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`.
- Проект лежит в `C:\Users\zakco\VS Code\ikan`, внутри локальный git.
- Запуск: `npm run dev`, адрес `http://localhost:3000`. С телефона в той же
  сети открывается по адресу компьютера и порту 3000.

`npm audit` показывает пять уязвимостей. Все в одной цепочке проверщика кода
(`eslint-config-next`), на сайт они не попадают. `npm audit fix --force` не
запускать: откатывает настройки с 16-й версии на 14-ю.

## Что решено

Стек: React в варианте Next.js 16.4.0, TypeScript, Tailwind 4. Страницы
собирает сервер, это нужно для рекламы и поиска. Админка пока не выбрана,
вернёмся к ней после вёрстки.

Порядок работы: по одной странице, сразу компьютер и телефон.

Шрифты: заголовки Manrope, текст Onest. Названий от дизайнера нет, шрифты
определены сравнением с макетом по буквам. Оба свободные, лежат в
`app/fonts` и отдаются с нашего сайта, без обращения к Google.

Тексты главной взяты из макета для компьютера.

## Как устроен проект

```
app/layout.tsx        общая обёртка: шрифты, заголовок вкладки, язык
app/page.tsx          главная, собирается из блоков
app/globals.css       цвета, шрифты, общие размеры
app/fonts.ts          подключение шрифтов
content/site.ts       телефон, меню, подвал
content/home.ts       все тексты и картинки главной
components/site/      шапка, меню для телефона, подвал, форма, две кнопки
components/home/      шесть блоков главной
components/ui/        иконки из макета
public/images/        логотипы и фотографии
```

Тексты отделены от вёрстки специально: когда появится админка, она подменит
файлы из `content`, вёрстку трогать не придётся.

Ширины: до 768 вид для телефона, от 1024 вид для компьютера, между ними
промежуточный. Макет нарисован на 1171 и 402.

## Где отступил от макета и почему

- Макеты компьютера и телефона расходятся по текстам: разные заголовок,
  подзаголовок, описания первых четырёх строк, фото в тёмной плашке. На
  сайте текст один, взят с компьютера.
- В макете телефона у строк с фотографиями справа синяя полоса, фотография
  не дотянута до края. Сделал во всю ширину.
- Меню для телефона на макете главной не нарисовано. Сделал выпадающую
  панель: пункты, телефон, кнопка заявки.
- Две кнопки «Позвонить» и «Оставить заявку» закреплены справа внизу только
  на компьютере, как в макете. У подвала они прячутся, чтобы не закрывать
  форму.
- На широких экранах колонка остаётся 1024, строки с фотографиями идут во
  всю ширину окна.

## Вопросы к заказчику через Сашу

Новые, по главной:

1. Какой текст верный, с компьютера или с телефона.
2. Цифры доходности спорят между собой: «до 30% годовых» и
   «12% годовых · от $5 000» на одной странице, на старом сайте «от 25%».
3. Настоящий телефон.
4. Исходники фотографий. Присланные совпадают с размером в макете, на
   экранах с высокой чёткостью и на телефоне будут мягкими.
5. Логотип в кривых. В присланных SVG внутри лежит картинка 177 на 36.
6. Названия шрифтов от дизайнера, чтобы подтвердить Manrope и Onest.
7. Куда должны приходить заявки с формы.

Прежние, из стартового файла: сервер и домен, юридические документы, плашка
про cookie, второй язык, расчёт дохода, ресторан.
