# Сайт ИКАН: вики

Сайт агентства недвижимости ИКАН (Сербия, Златибор): квартиры для жизни, для сдачи в аренду, новостройки, инвестиции, ресторан в аренду. Сделан один в один по макетам Figma, для компьютера и телефона.

Данные (объекты, тексты, фото, телефоны, ссылки соцсетей) сайт берёт из бэкенда `backend-ikan` (Laravel), его документация в репозитории бэкенда, `docs/README.md`.

- Репозиторий: https://github.com/Zakirov-Yuriy/ikan
- Показ заказчику: https://ikan-khaki.vercel.app (Vercel, бесплатный тариф)
- Бэкенд для показа: https://backend-ikan.onrender.com (Render, бесплатный тариф)

## Стек

- Next.js 16.4 (App Router), React 19, TypeScript.
- Tailwind CSS 4, свои шрифты Manrope и Onest в `app/fonts/` (подключаются в `app/fonts.ts`).
- Node 22 (файл `.node-version` для хостинга; нужен Node от 20.9).
- Без сторонних библиотек интерфейса: окна, вкладки, плашка cookie, «Поделиться» написаны сами.

## Запуск на компьютере

1. Запустить бэкенд (`php artisan serve` в папке `backend-ikan`), он отвечает на http://localhost:8000.
2. В папке сайта файл `.env.local`:
   ```
   BACKEND_URL=http://localhost:8000
   ```
   Без него сайт тоже ищет бэкенд на http://localhost:8000.
3. `npm install` (один раз), затем `npm run dev`. Сайт на http://localhost:3000.
4. С телефона в той же сети: адрес компьютера, например `http://192.168.1.5:3000`. Адреса домашних сетей разрешены в `next.config.ts` (`allowedDevOrigins`).

Сборка как на хостинге: `npm run build`, затем `npm run start`. Проверка кода: `npm run lint`.

Если бэкенд не запущен, страницы с данными показывают ошибку «Бэкенд не отвечает по адресу ...». Главная не откроется, пока в бэкенде не загружены её тексты (`php artisan db:seed --class=HomeSeeder`).

## Страницы

| Адрес | Страница | Данные |
|---|---|---|
| `/` | Главная | `GET /api/home` |
| `/dlya-sebya` | Квартиры для собственного проживания | `GET /api/pages/living`, `GET /api/apartments?catalog=living` |
| `/dlya-arendy` | Квартиры для сдачи в аренду | `pages/renting`, `apartments?catalog=renting` |
| `/novostroyki` | Новостройки в Сербии, вкладки по стадии | `pages/newbuilds`, `apartments?catalog=newbuilds` |
| `/apartamenty/[slug]` | Страница апартамента | `GET /api/apartments/{slug}` |
| `/apartamenty/[slug]/foto` | Все фото апартамента | то же |
| `/restoran` | Ресторан в аренду | `GET /api/restaurant` |
| `/restoran/foto` | Все фото ресторана | то же |
| `/investitsii` | Инвестиции | тексты в коде, `content/investments.ts` (в админке пока нет) |
| `/dokumenty/[slug]` | Юридические документы: `politika-konfidencialnosti`, `polzovatelskoe-soglashenie`, `soglasie-na-obrabotku-personalnyh-dannyh`, `soglasie-na-reklamu`, `oferta` | тексты в коде, `content/documents.ts` |
| `/api/request` | Приём заявки с форм, не страница | передаёт в `POST /api/requests` бэкенда |

На каждой странице общие настройки: `GET /api/site` (телефоны, ссылки соцсетей).

Страницы с данными собираются при каждом открытии (`force-dynamic`, запросы без кэша): всё, что сохранили в админке, видно после обновления страницы. Запросы к бэкенду идут с сервера сайта, браузер посетителя бэкенд не видит.

## Папки

```

                     картинка превью ссылки opengraph-image.png
components/site/     общее на всех страницах: шапка, подвал, меню телефона, окна,
                     формы заявки, плашка cookie, закреплённые кнопки, «Поделиться»
components/home/     блоки главной
components/catalog/  списки квартир: карточка, вкладки ЖК и стадий
components/object/   страницы апартамента и ресторана: галерея, карточка справа,
                     характеристики, страница «Все N фото»
components/invest/   блоки страницы инвестиций
components/ui/       иконки из макета (SVG)
content/             постоянные подписи и тексты, адреса страниц (paths.ts),
                     типы данных; тексты инвестиций
lib/api.ts           все запросы к бэкенду и перевод ответов в формы блоков
lib/request.ts       отправка заявки с формы

```

## Как устроены основные части

**Шапка и подвал** (`Header.tsx`, `Footer.tsx`). Телефоны из админки: в шапке на компьютере оба столбиком, в подвале оба друг под другом и в нижней строке. Кнопки «Позвонить» звонят на главный телефон. Иконки MAX, Telegram, ВКонтакте открывают ссылки из админки в новой вкладке. Если ссылка в админке пустая, иконки нет. «О компании» прокручивает к блоку на главной (`AnchorLink.tsx`).

**Галочки под формами** (`Consents.tsx`, тексты в `content/site.ts`, `consents`): «Я принимаю условия Пользовательского соглашения и Политики конфиденциальности.» и «Я даю согласие на обработку моих персональных данных.» обязательные, без них форма не отправляется; «Я согласен на получение рекламных и информационных сообщений.» по желанию, уходит в заявку как `consent_ads`. Ссылки в галочках открывают документы в новой вкладке, чтобы не потерять заполненную форму.

**Документы** (`LegalPage.tsx`, `content/documents.ts`). Пять документов от заказчика, текст перенесён из файлов Word один в один. Править текст в `content/documents.ts` (поле `html`). Ссылки на все пять в нижней строке подвала; «Политика конфиденциальности» ещё в колонке «Документы».

**Поле телефона** (`lib/phone-prefix.ts`): при нажатии в пустое поле само появляется «+7 », код можно стереть и ввести другой; если ушли из поля, ничего не набрав, «+7» убирается. Вставка номера целиком («+7 ...», «8...», «+381 ...») заменяет «+7 », а не дописывается к нему.

**Заявки.** Две формы: «Заказать обратный звонок» в подвале (`CallbackForm.tsx`) и окно «Оставить заявку» (`RequestSheet.tsx`, на компьютере по центру, на телефоне выезжает снизу). Обе отправляют заявку через `/api/request` в бэкенд. Есть поле-ловушка для роботов. После отправки открывается подтверждение «Заявка отправлена» (`RequestSent.tsx`). При ошибке под формой текст с телефонами для звонка. Какие кнопки открывают окно, а какие прокручивают к форме в подвале, решает `RequestPopup.tsx`.

**Закреплённые кнопки.** На компьютере справа внизу «Поделиться», «Позвонить», «Оставить заявку» (`FloatingActions.tsx`), на телефоне полоса внизу экрана (`MobileBar.tsx`). «Поделиться»: на https телефон показывает системное окно, иначе своё окно с Telegram, WhatsApp, ВКонтакте, почтой и копированием (`ShareSheet.tsx`).

**Плашка cookie** (`CookieConsent.tsx`, `CookieSettings.tsx`). «Принять все» или «Настроить» с выбором аналитики и маркетинга. Выбор хранится в браузере посетителя (`lib/cookie-consent.ts`).

**Главная.** Все тексты, фото и порядок строк из админки «Главная сайта». «Актуальные объекты»: до трёх апартаментов с галочкой «На главной» в порядке списка апартаментов; если галочки нет ни у одного, первые три из списка. Пять строк блока «Что мы предлагаем» на компьютере нажимаются целиком, на телефоне по фото. Карточки объектов нажимаются целиком.

**Списки квартир.** Вкладки по жилым комплексам: показываются только ЖК, где на этой странице есть хотя бы один апартамент. Карточка нажимается целиком.

**Страница апартамента.** Галерея (любое фото открывает «Все N фото»), карточка справа с ценой и кнопками, характеристики, данные. В карточке справа тип, площадь и этаж: если тип длинный и всё не помещается в строку, площадь и этаж уходят на вторую строку.

**Превью ссылки.** В Telegram, WhatsApp, ВКонтакте показывается картинка `app/opengraph-image.png` (логотип на тёмно-синем, 1200 на 630), заголовок и описание своей страницы. Telegram запоминает превью: для старой ссылки обновить через бота @WebpageBot.

**Нажатие по всей карточке.** Прозрачная ссылка поверх блока (`absolute inset-0`, скрыта от клавиатуры и программ чтения с экрана), настоящие ссылки поверх неё (`relative z-[2]`). Для клавиатуры остаются обычные ссылки.

## Настройки окружения

| Переменная | Где | Зачем |
|---|---|---|
| `BACKEND_URL` | `.env.local`, Vercel | адрес бэкенда; по нему же разрешены фото в `next/image`, поэтому после смены адреса сайт пересобрать |
| `SITE_URL` | Vercel, необязательно | полный адрес сайта для картинки превью; на Vercel адрес подставляется сам |

## Хостинг (показ заказчику)

Vercel, проект подключён к репозиторию GitHub: каждая отправка в `main` сама пересобирает сайт. Бесплатный тариф Vercel только для некоммерческого использования, и из России с мобильного интернета сайты на Vercel открываются не всегда. Для постоянной работы нужен свой хостинг (решается отдельно).

## Правила в коде

- Комментарии и тексты на русском.
- Файлы, оформленные вручную, prettier не прогоняется: `components/home/*`, `components/site/Header.tsx`, `Footer.tsx`, `MobileMenu.tsx`, `FloatingActions.tsx`, `CallbackForm.tsx`, `RequestSheet.tsx`, `content/home.ts`, `app/page.tsx`. Остальные файлы можно форматировать prettier.
- Размеры и отступы сняты с макетов до долей пикселя; при правках сверять с Figma.

## Проверки

Каждая правка проверяется в браузере (Playwright) на ширинах 390, 1024, 1280, 1440 px: переходы, формы, окна, клавиатура, консоль без ошибок. Скрипты проверок лежат у разработчика, не в репозитории.
